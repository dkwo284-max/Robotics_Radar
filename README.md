휴머노이드·피지컬 AI **27개사의 양산·자금·IPO·부품 기회**를 **한국 제조·부품사 경영진**과 **투자(비용 대비 효율)** 관점에서 정리한 대시보드입니다.

## 점수

- **경쟁력(100)** = 기술 30 + 양산 30 + 자본 20 + 실행 신뢰도 20 → Tier 1 ≥ 70, Tier 2 ≥ 50, 나머지 Tier 3
- **고객 매력도(100, 하드웨어 기업만)** = 양산 30 + 조달 개방성 25 + 지정학 접근성(한국 부품사 기준) 25 + 지불 능력(자본) 20
- 점수가 바뀐 날마다 `data/history.json` 에 스냅숏을 남겨 점수 변화·Tier 이동을 경보로 보여줍니다.

## 동작 방식

- `.github/workflows/update.yml` 이 매일 UTC 19:10(뉴질랜드 오전) 실행 → `scripts/update.py`
  - **Google 뉴스 RSS**: 기업별 검색어(영어·한국어). 처음 한 번만 30일치를 모으고(백필), 그다음부터는 마지막 수집 이후 며칠분(최대 7일)만, 이미 본 기사는 건너뜀
  - **Gemini 무료 등급**: 기사 60건씩 묶어 분류(관련성·유형·중요도)·한국어 요약·수치 추출. 새 기사 먼저, 그다음 태그가 없는 지난 기사. 내 보장량 3회 + 허브 공유 예비분(My Hub `budget.json`, 하루는 오클랜드 00시 기준) 중 오늘 남은 몫만큼만 쓰고 나머지는 다음 실행에서 이어서(`web/data/ai-usage.json`, `scripts/budget.py`, 허브의 다른 앱과 같은 키를 씀)
  - 분류할 때 '누가 봐야 하는지(경영진·기술전략·엔지니어)', 기술 층, 관련 신호도 함께 붙임(추가 호출 없음)
  - **특허·지재권 소식**: 기업별 특허 키워드 질의(`config.json` 의 `patent_queries`)를 같은 구글 뉴스 RSS 로 수집 — 분류는 위 Gemini 호출 안에서 `type=patent` 로 함께
  - **Yahoo Finance**: 관련 상장사 11종목 종가(키 불필요) — 날짜별 종가를 쌓아 두고 평소엔 최근 10일만 받아 합침(처음에만 3개월)
  - **논문 신호**: arXiv API(키 불필요)로 월별 건수를 쌓음 — 처음엔 층 11개 × 24개월 ≈ 264회(약 15분), 이후 주 1회 20회 안팎(요청 간격 3.5초)
  - **주간 다이제스트**: 직전 요약이 6일 넘으면 그날 남은 AI 한도로 1회(역할별 한 줄 결론·근거 소식·다음 주 할 일)
  - `scripts/build.py` 가 점수·경보를 계산해 `dashboard.json` 생성 → 커밋 → GitHub Pages 배포
- data·scripts·web 을 푸시하면 수집 없이 빌드·배포만 합니다. 커밋 메시지에 `[collect]` 가 있으면 수집도 함께 실행합니다.

| 방식 | 내용 | 접근 조건 |
|---|---|---|
| **조회 허브**(링크 전용) | 기업 × 기술 층 칸에서 에스페이스넷 검색이 열림. 검색식 복사 기능. 기업별 보기·전체 한눈에(히트맵), 선택 기간에 새 소식·근거가 있는 칸만 강조. 데이터를 저장하지 않음 | 없음. 에스페이스넷 검색식 형식은 실제 열어 확인(예: `pa="ubtech" and cpc=B62D57/032` → 결과 표시) |
| **특허·지재권 소식**(보도 기반) | 기업별 특허 키워드로 매일 수집한 뉴스를 AI 가 분류 | 키 없음(구글 뉴스 RSS) |

| **논문 신호**(arXiv) | 기술 키워드가 초록에 나온 로봇 논문 수 — 월별 24개월 시계열, 최근 12개월 vs 직전 12개월(산점도·덤벨·추이선) | 키 없음. 설명 메타데이터는 CC0(약관 확인), 요청 3초에 1회 |

- 한계: 건수·추이는 직접 보여주지 못합니다(조회 허브로 직접 확인). 논문은 특허보다 앞서는 **선행 신호**일 뿐 산업 동향과 다를 수 있고, 하모닉 감속기·롤러스크류는 논문 초록에 거의 나오지 않아(최근 12개월 1편·0편) 측정하지 않습니다. 침해·회피 판단은 특허팀 몫입니다.
- 화면의 출처 유형 배지: 링크 전용 / 보도 기반 / 분기 큐레이션 / 논문 신호 / EPO 집계(선택 기능).

### 선택 기능: EPO OPS 집계 (기본 꺼짐)

출원인 × 기술 층 **공개 건수**를 직접 세고 싶을 때 쓰는 경로입니다. 코드(`scripts/patents.py`, `scripts/patent_calc.py`)와 테스트는 남겨 두었고 기본은 꺼져 있습니다.

- 켜려면: ① https://developers.epo.org 에서 가입·앱 생성(무료, 주 4GB 한도) → Consumer Key·Secret 을 Secret `EPO_OPS_KEY`, `EPO_OPS_SECRET` 으로 등록 ② `data/patents_cfg.json` 의 `enabled` 를 `true` ③ 워크플로 `Collect` 단계 `env` 에 두 Secret 추가 ④ 먼저 `python scripts/patents.py --probe` 로 키·검색식·응답 구조 점검.
- **개별 특허 레코드(번호·제목·출원인)는 저장·공개하지 않습니다**(`publish_records: false`). EPO 약관 3.2항이 데이터를 "그 자체로" 공개하는 것을 금지하고 위반은 즉시 해지 사유(8.3)라서, 건수·비율만 남깁니다. 허용 여부를 EPO(patentdata@epo.org)에 확인한 뒤에만 켜세요.
- 약관 요점: 계정·앱을 여러 개 만들어 한도를 피하면 중대 위반 · 키는 본인 전용·비밀 유지 · 약관·한도 변경은 이메일 통지(2개월 뒤 효력). 한도를 넘는 다운로드는 청구 정보를 입력해야만 가능(입력하지 않으면 차단).
- **무료 한도 보호**: 받은 응답 크기를 직접 세어 주 2,000MB(무료의 50%)·하루 400MB 를 넘길 것 같으면 요청을 보내지 않고 중단, 코드에 무료 한도의 80% 절대 상한, OPS 가 quota 거부하면 즉시 중단.
- 건수가 크게 바뀐 칸만 변화 로그에 남기며(기준값은 기록된 칸만 갱신), 공정 이용 헌장대로 요청 간격 7초·야간(GMT 19~07시) 실행을 권장 구간에 둡니다.

## 의사결정 보조 기능 (모두 기존 데이터만 사용, 추가 수집·비용 없음)

- **영업 우선순위 보드**(경영진·부품사 관점): 고객 매력도 × 부품 원가 비중 × 국내 공백 가산 × 비중국 대체 수요 가산 − 자체 생산 감점. 규칙은 `scripts/build.py` 의 `sales_board` 에 있고 점수는 추정입니다.
- **발표 대비 실제 이력·90일 마일스톤**(기술전략): 큐레이션된 로드맵 상태(달성·지연·시점 경과)를 세고, 앞으로 90일 안에 끝나는 계획을 보여 줍니다.
- **점수 민감도**(자원 탭): 기술·양산·자본·실행 가중치를 바꿨을 때 순위·Tier 변화와, 5가지 가중치에서의 순위 범위(견고/민감).
- **큐레이션 신선도**(경영진): 기준일이 6개월 넘은 값을 '오래됨'으로 표시하고 갱신 대기 목록을 보여 줍니다.
- **뉴스 품질**: 같은 사건을 여러 매체가 낸 기사는 대표 1건으로 묶고('외 N곳 보도'), 시장 전체 질의로 모은 특허 기사는 휴머노이드·피지컬 AI 단어가 있어야 남깁니다(`scripts/news_cluster.py`, 원본 `news.json` 은 그대로).
- **화면 링크 공유**: 홈의 '링크 복사'가 역할·기간·기업·기술 층 선택을 주소에 담습니다(`#home?role=engineer&period=30&patCo=bd`).
- **국가 레이더 소유 기준 점선**: `data/strategy.json` 의 `countries.owner_basis` 로 가중치·대상 기업을 조정합니다.

## 중복 수집 없이 업데이트만 (증분 수집)

| 데이터 | 처음 | 이후 |
|---|---|---|
| 뉴스·특허 소식 | 30일치 1회(`backfill_days`) | 마지막 수집 이후 며칠분만(2~7일), 이미 본 기사 id·버린 기사 id 는 건너뜀 |
| AI 분류 | 새 기사 먼저 | 분류 못 한 기사만 다시(30일 안), 하루 상한 안에서 이어서 |
| 주가 | 3개월 | 최근 10일을 받아 날짜별로 덮어씀 |
| 논문 신호 | 24개월(≈264회) | 확정된 달은 다시 세지 않고 최근 달만 6일마다 갱신 |

- 백필 중 질의의 20% 넘게 실패하면 '30일 확보'로 치지 않고 다음 실행에서 다시 시도합니다.
- 화면의 7일/30일 선택은 모은 기간까지만 보여 줄 수 있습니다. 모은 기간보다 긴 구간을 고르면 상단에 '소식은 ○/○부터' 안내가 뜹니다.

| 외부 호출 | Google 뉴스 RSS · Yahoo Finance 차트 · Gemini API · arXiv API | 모두 키 없음 또는 무료 키. EPO 는 꺼짐 |
| Secrets | `GEMINI_API_KEY` 하나 | 결제 수단이 필요한 서비스 없음 |
| Gemini | 내 보장량 3회 + 허브 공유 예비분(세 앱 합산·오클랜드 00시 리셋), 요청당 HTTP 최대 3회(`max_http_attempts`) | **키는 결제(Billing)를 연결하지 않은 AI Studio 무료 프로젝트 것이어야 합니다.** 결제 연결 프로젝트의 키는 한도를 넘으면 과금될 수 있습니다 |
| 비상 스위치 | `config.json` 의 `llm.enabled: false` | 키가 있어도 AI 를 전혀 쓰지 않고 제목만 표시 |
| GitHub | 공개 저장소의 Actions·Pages 는 무료 | 비공개로 바꾸면 Actions 월 2,000분(Free)을 쓰며, 이 앱은 실행당 약 1분 |
| EPO | 기본 꺼짐, 응답 크기 직접 계산해 무료 한도 50%에서 중단 | 한도 초과 다운로드는 청구 정보를 입력해야만 가능 |
| 비공식 엔드포인트 | Google 뉴스 RSS · Yahoo 차트 | 공식 보장이 없어 막히면 지난 값을 유지하고 경고만 표시(과금 없음) |

## 처음 설정

1. Settings → Pages → Source 를 **GitHub Actions** 로
2. Settings → Secrets and variables → Actions 에 `GEMINI_API_KEY` (Daily Brief·웨일 레이더와 같은 키 — 무료 한도를 함께 씀). 없으면 제목만 표시
3. Actions → Robotics Radar update → Run workflow (이후는 매일 자동 실행). 특허·논문 기능에 별도 계정·키는 필요 없습니다

## 로컬 실행

```bash
pip install -r requirements.txt pytest
python -m pytest -q
python scripts/update.py          # 뉴스·주가·논문 신호 수집 + 빌드 (GEMINI_API_KEY 없으면 제목만)
python scripts/papers.py --force  # 논문 신호만 다시 세기
python scripts/build.py           # 빌드만
python -m http.server -d web 8000
```

## 주의

점수·인사이트·국가 평가는 공개 정보를 바탕으로 한 분석이며 투자 권유가 아닙니다. 회사 발표 수치(특히 생산 목표)는 실제와 다를 수 있어 실행 신뢰도 점수로 따로 평가합니다. 뉴스 요약은 RSS 제목·짧은 설명을 근거로 한 AI 추정입니다.
